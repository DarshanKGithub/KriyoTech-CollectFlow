# Subscription Plans

Plan prices and limits are database configuration, never frontend constants. Reviewed India SME launch defaults (6 November 2026): Trial ₹0/20 invoices/2 users; Starter ₹1,499 monthly/₹4,497 quarterly/₹14,990 annual/100 invoices/3 users; Growth ₹3,499/₹10,497/₹34,990/400/10; Control ₹5,999/₹17,997/₹59,990/1,200/read-only unlimited; Enterprise custom. Currency defaults to INR. Annual payment equals ten monthly payments; quarterly equals three. Existing usage limits and entitlement grants are unchanged by the price review. See `docs/pricing-market-review-2026-11-06.md` for evidence and assumptions.

Subscription periods store plan, cycle, status, start/end, next billing, trial end, grace period, and auto-renew. Treat amounts as minor units (paise); show formatting only at presentation. Enterprise custom amounts may be null.

Standalone packages (per company, five users): Reconcile ₹499/month, ₹1,497/quarter, ₹4,990/year; SettleView ₹499/₹1,497/₹4,990; Transport ₹2,499/₹7,497/₹24,990; DriverFinance ₹799/₹2,397/₹7,990. Run `python manage.py seed_solution_plans` to add missing packages with explicit access grants. It retains existing package edits and never moves current subscriptions. Standard catalog seeding also creates these packages. One plan is selected per subscription; package and individual-feature prices are alternative catalog representations, not cumulative checkout charges.

Preview revised prices using `python manage.py apply_launch_pricing`; save with `--apply`. Every changed Feature/Plan records an audit event. Existing pending Payment amounts, BillingInvoice amounts, subscriptions, access grants, Enterprise pricing and custom plan slugs are retained. Subsequent new orders for the standard plans use the new catalog rate; feature catalog fees remain separate estimates until feature checkout is implemented.
